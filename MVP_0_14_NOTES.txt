MOJO Drive MVP 0.14 — Conservative Multi-Approach Road Geometry Shadow

---------------
0.14 is intentionally NOT a camera-engine retune.
The field-validated 0.12 runtime remains the locked production decision engine.
The successful 0.13 field trip is added to regression/replay coverage, but Road Geometry
still has ZERO authority over live alerts.

Locked behavior preserved:

- Confirmation scores / hit counts
- Adaptive warning distance
- First audible alert guarantee

- Overspeed behavior

1) FIELD RESULT THAT DROVE 0.14
--------------------------------
The 0.13 shadow test confirmed the stable engine again, but exposed one important Road
Geometry problem: real camera 14302 was correctly warned by the stable engine while the
first shadow policy reported conflict because its learned polyline was incomplete/far away.

That result is the reason 0.14 stays SHADOW ONLY.
No geometry result can confirm, reject, suppress, delay or create a camera alert.

2) CONSERVATIVE SHADOW POLICY V2
---------------------------------
RoadGeometryShadow now uses policy:
  conservative_multi_approach_v2

Key changes:
- Multiple field-proven approaches can coexist for the same physical camera.
- A support/weak-support candidate wins over a different conflicting learned approach.
- Far from learned geometry is now outside_coverage, NOT conflict.
- conflict is emitted only when the car is close to learned geometry AND heading strongly
  disagrees with the usable learned route.
- A gray zone remains uncertain instead of forcing a positive/negative conclusion.
- Logs include policy, selected segment ID, number of segments considered and number of
  segments currently in coverage.
- roadGeomEngineEffect=false is explicitly logged.

Current thresholds are diagnostic only:
  support          <= 70 m corridor and <= 50 deg heading delta
  weak_support     <= 160 m corridor and <= 65 deg heading delta
  conflict         <= 180 m coverage and >= 105 deg heading delta
  uncertain        in coverage but not strong enough either way
  outside_coverage > 180 m from all learned geometry
  position_only    geometry nearby but no usable vehicle bearing

5) NEW CI GUARD FOR ROAD GEOMETRY
----------------------------------
GitHub Actions now runs, in this order:
1. Stable v0.12 engine hash/constant guard
2. Four-trip camera replay regression
3. Conservative Road Geometry shadow regression cases
4. Android debug APK build
5. APK artifact upload

A shadow-policy mistake can therefore fail CI before the APK is produced, without touching
the production camera engine.
